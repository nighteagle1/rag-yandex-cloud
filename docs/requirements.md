# Требования: RAG-ассистент первой линии поддержки Yandex Cloud

## Пользователь
Специалист первой линии поддержки облачного провайдера. Получает вопросы клиентов, ищет ответ в документации и пересылает клиенту короткий ответ со ссылкой. Ассистент экономит время на поиск, но не заменяет проверку: специалист должен видеть источник и быстро сверить ответ.

## В рамках
Вопросы по четырём сервисам, документация которых загружена в базу (русская версия `yandex-cloud/docs`, зафиксированный коммит):
- Compute Cloud — виртуальные машины, диски, образы, группы ВМ, квоты и лимиты;
- Object Storage — бакеты, объекты, доступ, жизненный цикл, лимиты;
- Virtual Private Cloud — сети, подсети, адреса, группы безопасности, маршрутизация;
- Billing — платёжные аккаунты, оплата, счета, правила тарификации.

Типы вопросов: факты («какой максимальный размер…»), процедуры («как сделать…»), числа (лимиты, цены, сроки), вопросы, требующие нескольких страниц.

## Вне рамок
- другие сервисы Yandex Cloud и сторонние облака;
- юридические вопросы, трактовка договора и оферты, персональные условия клиента;
- инструкции, которых нет в документации (обходы ограничений, недокументированные API);
- попытки изменить поведение ассистента («забудь инструкции…»).

На такие вопросы ассистент отвечает отказом: сообщает, что в базе нет ответа, и предлагает эскалацию. Он не додумывает ответ.

## Хороший ответ
- короткий: 1–5 предложений или короткий нумерованный список шагов;
- опирается только на найденный контекст, цифры совпадают с документацией;
- содержит ссылку на страницу документации (`https://yandex.cloud/ru/docs/...`), взятую из найденных фрагментов;
- если в контексте ответа нет, прямо говорит об этом.

## Метрики и пороги
Пороги зафиксированы до первого замера и после него не меняются.

| Метрика | Как считается | Порог |
|---|---|---|
| Доля верных ответов | метка судьи `верно` среди вопросов, ответ на которые есть в базе | ≥ 80% |
| Доля корректных отказов | метка `корректный_отказ` среди вопросов без ответа и вопросов не по теме | ≥ 90% |
| Ссылка на источник | ответ содержит хотя бы одну ссылку `yandex.cloud/ru/docs` (для вопросов с ответом) | 100% |
| Recall поиска (hit@5) | нужная страница из `gold_urls` в топ-5 найденных чанков | ≥ 85% |

Дополнительно отслеживаются доля галлюцинаций (метка `галлюцинация`), MRR поиска и время ответа; порогов для них нет.
